## Title

HandoffReady Delivery Room: from a shared conversation to a reviewed delivery record

## Short description

A Switch-connected delivery workflow for small web/design teams. An agent stages received files and asks evidence-linked questions; a local lead reviews scope, confirms corrections and authorizes one exact record to return to the room.

## Problem

A delivery folder can look complete while the purpose of a file remains unclear or a correction makes an earlier assessment obsolete. Chat conversations, file checks and final review often become disconnected. HandoffReady links those steps while keeping human judgment explicit.

## What Switch does

Discord messages and attachments reach the dedicated Switch-managed agent. Its bounded command bridge stages actual received bytes, reads current checks, proposes contextual questions and records unverified replies. The local reviewer checks sources and decides what context and packet are current. After explicit local authorization, the agent can consume one permission to return the frozen Markdown record to the configured main channel. An uncertain send stays unverified until the lead checks the actual returned file and destination.
