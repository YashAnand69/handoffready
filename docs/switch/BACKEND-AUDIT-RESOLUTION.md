# Backend audit claim resolution

6 November 2026. Reviewed `BACKEND_BUGS_REPORT.md`, the backend matrix/security/metrics sections of `AUDIT_REPORT.md`, and backend suggestions/roadmap in `SUGGESTIONS_REPORT.md` as untrusted claims. This document supersedes their proposed backend fixes where dispositions differ. Frontend and CLI implementation belong to the parent; neither was modified here. No live state, credentials, configuration, server restart, external message, commit or publication was involved. Frozen evaluation artifacts were not changed.

## Changes supported by reproduction

- **Parser cleanup failure:** an explicit process double whose bounded `wait()` raises `TimeoutExpired` or `OSError` reproduced an escaping exception. The cleanup wait now preserves a safe blocked inspection result and releases the parser queue. This does not claim that an uninterruptible OS process was successfully reaped. `backend/handoffready/api.py:78`.
- **Streamed multipart overflow:** an authenticated chunked multipart request exceeding a reduced disposable request budget reproduced a Starlette `ExceptionGroup` escaping `call_next`. The existing streamed JSON test did not cover this path. Middleware now returns safe JSON413 when its own byte counter has recorded a limit breach; unrelated exceptions still propagate. No original file/project mutation occurs. Limits and authentication remain unchanged. `api.py:236`.
- **Missing extraction evidence:** a fake extraction adapter returning omitted/null quotation produced a generic failed job with `error_code=model_failed`. The error was already contained by the background worker; the report's claim of an unhandled HTTP crash was overstated. Missing evidence now follows the existing explicit `invalid_source_quote` rejection and cannot enter the checklist. `api.py:129`.
- **Image-check explanation:** the “every selected file” wording is broader than the implementation's selected-image subset. A wording correction was tried, then reverted when replay integrity correctly detected changes to its frozen source. Format-specific filtering is an explicit tested contract; neither checks source nor the frozen capture was changed in the final patch. Any wording change needs a separately labelled new capture, not an update to existing evidence. `backend/handoffready/checks.py:43`.

Five new regression cases in `tests/test_backend_audit_regressions.py` failed before the fixes and passed afterward: two cleanup failures, streamed multipart overflow, and omitted/null extraction quotes. They use disposable app data and explicit process/model doubles, not real model-performance or human-trial evidence.

## Related audit/suggestion dispositions

`AUDIT_REPORT.md` repeats the18 backend claims above; it adds no separate reproduced defect. Its blanket “air-gapped/no bytes to third parties” wording is inaccurate for configured supervised record return: deliberately projected public bytes can be sent through Switch/Discord. Raw source/brief/internal text is excluded, and return verification is explicitly operator confirmation, not independent transport authentication. Treat its percentage and full-suite claims as historical reported claims, not evidence of the cases this pass reproduced.

Backend suggestions3.1→BE-MED-09 (deferred platform hardening),3.2→BE-CRIT-01 (implemented),3.3→BE-HIGH-02 (existing layer contracts retained),3.4→BE-MED-08 (quota invariant retained),3.5→BE-MED-01 (unsupported injection path),3.6→BE-HIGH-01 (mixed-format semantics and frozen source retained). The corresponding roadmap priorities inherit these dispositions. Frontend suggestions and runtime/library upgrades remain outside this backend assignment.
