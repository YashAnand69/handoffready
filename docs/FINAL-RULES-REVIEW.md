## IP, privacy and open-innovation review

The application has an [MIT license](../LICENSE), [third-party notices](../THIRD-PARTY-NOTICES.md), locked dependency records and original [CC0 synthetic fixtures](../fixtures/README.md). The pinned [Google model card](https://huggingface.co/google/gemma-4-E2B-it/blob/3e22461f65e89153144f8adb70e3b8c2cc9845a7/README.md) identifies Apache-2.0, and [Google's license page](https://ai.google.dev/gemma/apache_2) supplies its terms. The conversion is credited to ggml-org. Project licensing does not replace model/runtime/dependency terms. Reviewed source materials do not reveal a copied product, private client packet, external font or unlicensed artwork; this is not a complete chain-of-title investigation.

Before distributing bundled runtime, weights or compiled third-party frontend code, include their applicable license texts/notices. A names-and-license table alone is not a substitute for required redistribution notices. Keep ignored model/runtime installations, secrets, application databases, browser profiles and private sessions out of source publication. Review the exact final archive/repository contents; a clean tracked-file list alone cannot prove that every artifact is public-safe.

Approved checklist titles, descriptions and deliberate client notes enter exports. Raw brief/private fields are omitted, but confidential meaning copied into an approved public field is not automatically redacted. Use only the original synthetic packet for the public recording. Review screen contents, downloads and any shared agent session because the contest's promotional reuse rights extend to entry materials. Attribution in notices should also be summarized in the DEV article for significant upstream work.

The defensible open-innovation claims are: real local inference after explicit setup, no remote AI account or metered model API required for supported use, inspectable pinned foundations, and an editable workflow. Hardware, electricity and setup have costs; “free local execution” does not prove a zero-cost business. No closed-model comparator was run. Avoid saying the model is more accurate than a commercial API or that every closed API is inherently incompatible. Explain the actual privacy, reproducibility and control advantages implemented here.
