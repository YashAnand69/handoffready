# Public project showcase

Static Vercel deployment root. This is deliberately separate from the working React/FastAPI desk: no upload, live agent, database, secret or local-service proxy is included. Open `index.html` through a local static server or deploy this directory with Vercel CLI. No dependency install/build is required.

Assets are actual 6 November 2026 interface captures from an isolated synthetic layout fixture, with no saved user assessment. They do not represent a new Switch run or external participant trial. The new narrated integration demo remains pending. Screenshot source and capture details are recorded in `../docs/switch/AUDIT-POLISH-CHECKPOINT-20261106.md`.
