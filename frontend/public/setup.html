Your local delivery desk

The interface, database, file inspectors and AI run on your computer. Normal use has no remote inference bill. Initial dependency/model setup downloads software and about2.84GB of model weights; internet and enough local disk are required.

On the prepared Mac

Open the source folder and double-click Start HandoffReady.command. Keep that window open while using the app. It starts the installed local model and app; it does not purchase or install anything. 

.venv/bin/python scripts/start.py --with-model

If port8877 is occupied, use the existing app or stop the instance that owns it. The launcher will not replace another service.

Fresh source setup

Use Python3.12, Node22.12+ or24+, Apple command-line build tools, and about8GB free disk. The verified model installer targets an Apple Silicon Mac. Other model platforms have not been validated. 

python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-backend.lock
npm ci --prefix frontend
npm run build --prefix frontend
.venv/bin/python -m pip install --target .runtime/build-tools cmake==4.1.2
.venv/bin/python scripts/prepare_model.py
.venv/bin/python scripts/start.py --with-model

The installer verifies pinned model/runtime hashes and creates an owner-only local credential. It does not accept agreements or upload delivery files.

Manual mode

.venv/bin/python scripts/start.py

Without the model, you can add an explained checklist, inspect files, review mappings and export the handoff. AI buttons stay unavailable until the verified service is ready.

What this release handles

Pasted English briefs, up to20 requirements and30 files. Maximum50MiB packet/10MiB file, readable native PDFs up to10 pages, static images up to10 million pixels, PNG/JPEG, restricted SVG metadata, UTF-8 text and Markdown. No ZIP/Office/PSD import, OCR, external links or website execution.

Review before sharing

AI proposals can be wrong. Exact quotations prove source location, not satisfaction. Confirm format and meaning yourself. Manifest exports describe the packet; original files must be sent separately. Raw private fields are excluded, but approved titles/check descriptions/client notes are shared.

Private local storage

Projects normally live in your local application-data folder, outside the source repository. App storage is not encrypted. Use non-confidential examples for demonstrations. Read README.md and the review/evaluation records in docs/ for complete boundaries and setup details.
